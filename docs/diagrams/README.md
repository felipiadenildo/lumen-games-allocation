# Diagrams

| File | What it shows | How to edit |
|---|---|---|
| `pipeline-one-page.drawio` / `.png` | the whole pipeline on one page: inputs, the steps, the checks and the outputs | open the `.drawio` in [diagrams.net](https://app.diagrams.net) or the VS Code Draw.io extension, then export the `.png` again |
| `data-model.sql` / `data-model.svg` | the eight input tables and their keys | `data-model.sql` is the source: import it into a tool that reads SQL DDL (such as [drawDB](https://drawdb.app) or [dbdiagram.io](https://dbdiagram.io)) and export the `.svg` again |
